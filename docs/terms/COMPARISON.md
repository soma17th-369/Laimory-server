# 약관 기본틀 → 라이모리 변경 비교

이 문서는 공개된 표준약관·유사 서비스 문서에서 **어떤 구조를 참고했고 라이모리에 맞게 무엇을
수정·삭제·추가했는지** 검토하기 위한 비교표다. 외부 원문의 문장을 복제하지 않고 조항의 기능과
고지 구조를 요약한다. 정확한 외부 문장은 각 출처 링크에서 확인하고, 라이모리 문장은 연결된 초안이
단일 원문이다.

## 표시 방법

- 🟨 **수정** — 기본틀의 조항 목적은 유지하되 주체·항목·기간·효과를 라이모리 정책에 맞게 변경
- 🟥 **삭제** — 기본틀에 있지만 라이모리에 존재하지 않는 사업·기능·처리이므로 제외
- 🟩 **추가** — 기본틀에 없거나 부족하여 라이모리의 AI·위치·기록 처리에 맞게 신설
- ⬜ **유지** — 법정 고지 구조나 일반적인 권리 구조를 실질적으로 유지

하나의 행에 여러 표시가 있으면 기본틀 일부는 유지하면서 다른 부분을 삭제하거나 새 내용을 더했다는
뜻이다. 이 표는 법률 검토 결과가 아니라 **작성 근거와 편집 이력**이다.

## 현재 동의·확인 구조

아래는 최종적으로 지향하는 초기 약관 동의 흐름이다. #1·#3~#6의 현재 버전을 초기 화면에서 받고,
#8 개인정보 처리방침은 동의서가 아니라 언제든 열람하는 공개 문서로 제공한다.

| 화면·시점 | 문서 또는 확인 | 이용자 행위 | 현재 상태 |
|---|---|---|---|
| 초기 약관 동의 | #1 이용약관 | 동의 결과가 명확한 버튼 선택. 동의 버전·시각 기록 | 단일 enforcement gate 구현 |
| 신규 가입 | 만 14세 이상 확인 | 기본 해제된 `만 14세 이상입니다` 항목을 직접 확인. 약관 동의로 세지 않음 | 문서 반영. 생년월일·휴대전화 본인인증 정보는 수집하지 않고 실제 연령을 별도로 검증하지 않음 |
| 초기 약관 동의 | #8 개인정보 처리방침 | 링크로 열람. `처리방침에 동의`한다고 표현하지 않음 | 공개 API·seed 구현 |
| 초기 약관 동의 | #3 제3자 제공 · #4 민감정보 · #5 국외 이전 · #6 위치약관 | 현재 버전 4종을 초기 화면에서 받고 각각의 동의 이력을 기록 | 공개 조회·동의 등록·단일 enforcement gate 구현 |

따라서 화면상 구조는 `만 14세 이상 확인`과 초기 약관 동의 대상 5종, 상시 공개 개인정보 처리방침이다.
단순히 “로그인하면 이용약관과 개인정보 처리방침에 동의한 것으로 봅니다”라는
수동적 문구만으로 처리하지 않는다.
