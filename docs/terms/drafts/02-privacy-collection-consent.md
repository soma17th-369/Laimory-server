# 개인정보 수집·이용 동의

라이모리(이하 "회사")는 서비스 제공을 위하여 아래와 같이 개인정보를 수집·이용합니다. 내용을 확인하신 후 동의 여부를 결정하여 주시기 바랍니다.

## 1. 수집·이용하는 개인정보 항목

### 가. 회원가입 시

| 구분 | 수집 항목 | 수집 방법 |
| --- | --- | --- |
| 필수 | 소셜 계정 식별자, 닉네임 | 구글·카카오 로그인 시 자동 전달 |
| 필수 | 이메일 주소 | 구글 로그인 시 자동 전달 (카카오 로그인에서는 수집하지 않습니다) |

### 나. 서비스 이용 시

**회사는 회원이 직접 확인하고 선택하여 전송한 항목만 수집합니다.** 회원은 타임라인을 만들기 전에 기기에서 모아진 사진·위치·알림·일정을 하나씩 확인하고, 전송할 항목을 개별적으로 선택하거나 해제할 수 있습니다. 선택하지 않은 항목은 회사의 서버로 전송되지 않습니다.

| 구분 | 수집 항목 | 회원 선택 |
| --- | --- | --- |
| 필수 | 사진, 사진에 포함된 촬영 위치 | 건별 선택 |
| 필수 | 머문 장소·이동 경로의 위치 좌표, 이동수단, 이동 거리 | 건별 선택 |
| 필수 | 알림의 앱 이름·제목·내용 | 건별 선택 |
| 필수 | 일정의 제목·장소·설명 | 건별 선택 |
| **민감정보** | **걸음 수, 이동 거리, 수면 시간** | 선택 불가 |
| **민감정보** | **회원이 기록한 하루의 감정** | 회원이 직접 입력 |
| 필수 | 회원이 입력한 메모 | 회원이 직접 입력 |

민감정보의 처리에 관하여는 별도의 「민감정보 처리 동의」에서 정합니다.

| --- | --- |

## 2. 수집·이용 목적

1. 회원 식별과 로그인 유지
2. 하루 기록의 타임라인 자동 생성·표시·보관
3. 타임라인 생성 완료 알림 발송
4. 문의 대응, 부정 이용 방지 및 이용 제한 조치
5. 서비스 장애 대응과 안정성 확보

## 3. 보유·이용 기간

| 정보 | 보유·이용 기간 |
| --- | --- |
| 회원 정보 및 회원이 저장한 기록 | 회원 탈퇴 접수일로부터 5일 이내 파기 |
| 저장하지 않은 초안과 그에 딸린 사진 | 생성일로부터 7일 |
| 로그인 유지를 위한 인증 정보 | 발급일로부터 30일 |
| 접속 IP 주소 및 이용 기록 | 수집일로부터 6개월 |
| 개인위치정보 이용·제공사실 확인자료 | 기록일로부터 6개월 (위치정보법 제16조 제2항) |

관계 법령에 따라 보존하여야 하는 정보는 해당 법령이 정한 기간 동안 다른 정보와 분리하여 보관합니다.

## 4. 파기 절차 및 방법

보유 기간이 지나거나 처리 목적이 달성된 개인정보는 지체 없이 파기합니다. 전자적 파일은 복구할 수 없는 방법으로 영구 삭제하며, 사진 등 저장된 파일은 저장소에서 삭제합니다.

## 5. 동의를 거부할 권리와 거부 시 불이익

회원은 개인정보 수집·이용에 대한 동의를 거부할 수 있습니다. 다만 위 정보는 서비스 제공에 반드시 필요한 정보이므로, 동의하지 않으시는 경우 회원가입과 서비스 이용이 불가능합니다.

동의하신 이후에도 회원은 전송할 항목을 건별로 선택하거나, 언제든지 동의를 철회할 수 있습니다.

## 8. 개인정보의 안전성 확보 조치

1. 회원의 기록은 계정 식별자와 분리된 별도의 식별자에 연결하여 보관합니다.
2. 로그인 유지를 위한 인증 정보는 원문을 저장하지 않고 복원할 수 없는 형태로 변환하여 보관합니다.
3. 모든 전송 구간은 암호화된 통신(HTTPS)을 사용합니다.
4. 서비스 기록에 이메일·전화번호·카드번호 등이 포함된 경우 자동으로 가려서 저장합니다.
5. 개인정보에 접근할 수 있는 담당자를 최소한으로 한정합니다.
