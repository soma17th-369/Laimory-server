# 개인정보 국외 이전 동의

라이모리(이하 "회사")는 타임라인 생성과 알림 발송을 위하여 아래와 같이 회원의 개인정보를 국외로 이전합니다.

## 1. 이전되는 개인정보 항목

### 가. 인공지능 처리를 위하여 이전되는 항목

회원이 전송할 항목으로 직접 선택한 것만 이전됩니다.

1. 사진 및 사진에 포함된 촬영 위치
2. 머문 장소와 이동 경로의 위치 좌표, 주소, 주변 장소명, 이동수단, 이동 거리
3. 일정의 제목·장소·설명
4. 알림의 앱 이름·제목·내용
5. **걸음 수, 이동 거리, 수면 시간(민감정보)**
6. 기록의 날짜와 시간대

### 나. 회원의 기록 요약 정보를 갱신하기 위하여 이전되는 항목

1. 확정된 타임라인의 제목·부제·질문과 회원이 입력한 메모
2. **회원이 기록한 하루의 감정(민감정보)**
3. 이전 기록을 요약하여 회사가 보관하는 회원 요약 정보

### 다. 알림 발송을 위하여 이전되는 항목

1. 애플리케이션 설치 식별자, 타임라인 처리 상태

## 4. 동의를 거부할 권리와 거부 시 불이익

회원은 개인정보의 국외 이전에 대한 동의를 거부할 수 있습니다. 다만 인공지능 처리는 타임라인 생성 기능의 본질적인 부분이므로, 동의하지 않으시는 경우 **타임라인 생성 기능을 이용하실 수 없습니다.**

동의하지 않으시더라도 로그인, 이미 저장된 기록의 열람, 회원 정보 조회, 회원 탈퇴는 계속 이용하실 수 있습니다.

## 5. 동의의 철회

회원은 언제든지 국외 이전에 대한 동의를 철회할 수 있습니다. 앱 내 문의 또는 {{문의 이메일}}로 요청하실 수 있으며, 철회하시는 경우 타임라인 생성 기능의 제공이 중단됩니다.
