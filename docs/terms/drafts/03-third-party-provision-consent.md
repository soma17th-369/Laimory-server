## 2. 제공 시점과 범위

1. 타임라인 생성 정보는 회원이 타임라인 생성을 요청할 때 제공합니다. 사진·위치·알림·일정은 회원이 전송 대상으로 직접 선택한 것만 포함합니다.
2. 기록 요약 갱신 정보는 회원이 하루 기록을 저장한 뒤 매일 정해진 시각에 일괄로 제공합니다. 이때 사진은 제공하지 않습니다.
3. 회원의 닉네임, 이메일 주소와 소셜 계정 식별자는 어느 시점에도 제공하지 않습니다.

회사는 Amazon Web Services가 제공하는 Amazon Bedrock을 통하여 GPT-5.6 Luna 모델을 이용합니다.
Amazon Web Services, Inc.는 회원의 입력과 생성된 출력을 처리하며, 이를 인공지능 모델 학습을 위한
목적으로 이용하지 않습니다.

## 3. 동의를 거부할 권리와 거부 시 불이익

회원은 개인정보 제3자 제공에 대한 동의를 거부할 수 있습니다. 다만 인공지능 처리는 타임라인 생성 기능에 필요하므로, 동의하지 않으시는 경우 **타임라인 생성 기능을 이용하실 수 없습니다.**

동의하지 않으시더라도 로그인, 이미 저장된 기록의 열람, 회원 정보 조회와 회원 탈퇴는 계속 이용하실 수 있습니다.
