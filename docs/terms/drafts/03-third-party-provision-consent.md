# 개인정보 제3자 제공 동의

라이모리(이하 "회사")는 하루의 타임라인을 자동으로 생성하기 위하여 인공지능 서비스 사업자에게 회원의 개인정보를 제공합니다.

## 1. 개인정보를 제공받는 자와 제공 내역

| **제공받는 자** | **제공받는 자의 이용 목적** | **보유·이용 기간** |
| --- | --- | --- |
| **Amazon Web Services, Inc.** | **하루 기록을 해석하여 타임라인·제목·질문을 생성하고, 회원의 기록을 요약한 정보를 갱신** | **{{AgentCore 보관 기간}}** |

회사는 Amazon Web Services가 제공하는 Amazon Bedrock을 통하여 OpenAI 및 Amazon의 인공지능 모델을 이용합니다. 모델을 만든 사업자는 회원의 개인정보에 접근할 수 없으며, 개인정보는 Amazon Web Services의 네트워크 안에서만 처리됩니다.

## 2. 제공하는 개인정보 항목과 제공 시점

제공은 두 시점에 이루어지며, 시점마다 제공되는 항목이 다릅니다.

### 가. 타임라인을 생성할 때

회원이 타임라인 생성을 요청하는 시점에 제공하며, **회원이 전송할 항목으로 직접 선택한 것만** 제공합니다.

1. 사진 및 사진에 포함된 촬영 위치
2. 머문 장소와 이동 경로의 위치 좌표, 주소, 주변 장소명, 이동수단, 이동 거리
3. 일정의 제목·장소·설명
4. 알림의 앱 이름·제목·내용
5. **걸음 수, 이동 거리, 수면 시간(민감정보)**
6. 기록의 날짜와 시간대

### 나. 회원의 기록 요약 정보를 갱신할 때

회원이 하루 기록을 저장한 뒤, **매일 정해진 시각에 일괄로** 제공합니다. 사진은 이 시점에 제공되지 않습니다.

1. 확정된 타임라인의 제목·부제·질문과 회원이 입력한 메모
2. **회원이 기록한 하루의 감정(민감정보)**
3. 기록의 날짜와 시간대
4. 이전 기록을 요약하여 회사가 보관하는 회원 요약 정보

회원의 닉네임, 이메일 주소, 소셜 계정 식별자는 어느 시점에도 제공하지 않습니다.

## 3. 제공받는 자의 개인정보 이용 제한

제공받는 자는 위 이용 목적의 범위에서만 개인정보를 이용하며, 회원의 개인정보를 인공지능 모델의 학습에 사용하지 않습니다. 제공된 개인정보는 암호화되어 보관되며 위 보유·이용 기간이 지나면 삭제됩니다.

## 4. 동의를 거부할 권리와 거부 시 불이익

회원은 개인정보 제3자 제공에 대한 동의를 거부할 수 있습니다. 다만 인공지능 처리는 타임라인 생성 기능의 본질적인 부분이므로, 동의하지 않으시는 경우 **타임라인 생성 기능을 이용하실 수 없습니다.**

동의하지 않으시더라도 로그인, 이미 저장된 기록의 열람, 회원 정보 조회, 회원 탈퇴는 계속 이용하실 수 있습니다.
